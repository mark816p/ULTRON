## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/mark816p/ULTRON.git
cd ULTRON

# Install dependencies
npm install

# Run web development server
npm run dev

# Run native desktop mode (Electron)
npm run desktop

# Build production artifacts
npm run build
```
